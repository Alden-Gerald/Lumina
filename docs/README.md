## Reading notes

This repository is a personal experimental implementation with machine-dependent services. Some documents describe historical test setups, ideas, or future work. A roadmap checkbox is not proof a feature is released; check the current source and tests before relying on it.

Avoid copying machine-specific addresses, private host paths, certificates or credentials into issues and pull requests. Report potential security problems privately using [SECURITY.md](../SECURITY.md).
